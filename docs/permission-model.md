# 权限与风险模型

万象中枢连接的系统越多，越不能把所有工具暴露给 Agent 自由调用。权限模型必须在第一天建立。

## 风险等级

| 等级 | 含义 | 示例 | 默认策略 |
| --- | --- | --- | --- |
| L0 | 只读 | 网页读取、Obsidian 查询、GitHub issue 读取 | 自动执行 |
| L1 | 本地写入 | 写 Markdown、更新本地索引、生成项目上下文 | 自动执行 |
| L2 | 外部发送 | 飞书消息、Discord 回复、GitHub issue/comment | 白名单内自动，否则审批 |
| L3 | 外部发布 | X、小红书、B 站、公众号发布 | 必须人工审批 |
| L4 | 高风险执行 | shell、批量删除、账号操作、支付、复杂爬取 | 沙箱 + 人工审批 + 审计 |

## 最小权限原则

- Connector 只能拿自己需要的 token。
- Skill 不能默认继承全局权限。
- Agent 不直接持有高权限密钥。
- 发布类操作默认生成草稿，而不是直接发布。
- 爬取类操作必须记录来源、频率、账号、合规风险。

## 审批队列

审批项至少包含：

- 用户原始目标
- 将要执行的 Operation
- 输入摘要
- 目标平台与账号范围
- 风险等级
- 预期输出
- 可回滚性

未来 Web 控制台的第一批页面应包括任务列表、审批队列、连接器配置和审计搜索。
